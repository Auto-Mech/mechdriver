Sort a mechanism according to the specified criteria running:
```
mechanalyzer sortmech
```
In this example, add input specifications:
```
mechanalyzer sortmech -m DMM.CKI 
```

For additional info on input specifications,
```
mechanalyzer sortmech --help
```

Disclaimer: this examples aims at showing all classification criteria.
It is not advised to use all these criteria together, as it is meaningless.
The user should choose classification criteria according to needs.

this example exludes submechanism extraction, which is exemplified in the respective subdirectories.
